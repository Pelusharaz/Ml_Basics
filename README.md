# ML_Basics

A simple collection of machine learning exercises implemented from scratch using NumPy and Matplotlib.

## 📦 Contents
- **ex1-master** – Single-variable linear regression  
- **ex1-multi_linear_regression-master** – Multi-variable linear regression  
- **ex3–ex5** – Logistic regression, neural networks, and related practice tasks  

## 🛠 Setup
```bash
git clone https://github.com/Pelusharaz/Ml_Basics.git
cd Ml_Basics
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt


```
#Running 
Each exercise has its own folder. For example:
cd ex1-master/gepitanulas-ex1-master/ex1/src
python ex1.py
